# Cannabis Done Right

A static harm-reduction / decision-support site (Jekyll on GitHub Pages). Educational only, not medical advice.

- **Risk Check** (quiz.md): a 2-minute, risk-first quiz (situation, safety screen, three cited risk checks) whose reward is a conservative strain match. Hard stops (pregnancy, bipolar/psychosis history, under legal age, unanswered safety items) show no strain; driving soon defers; elevated-caution answers restrict matches to the lowest-risk pool. Nothing is saved or sent.
- **Strain Finder** (`finder.md`): ranks ~2,100 strains against selected conditions with a conservative risk penalty. Includes fictional **example profiles** that pre-select condition combinations.
- **Strain Breeder** (`breeder.md`): concept simulator.
- **Myths** (`myths.md`) and a quit-first reset on the home page.

## Layout

| Path | Purpose |
|---|---|
| `_data/strains_all.json` | Source strain dataset (`.jsonl` copy is used by `condition_profiles.py`) |
| `_data/example_profiles.json` | Example personas for the finder; add an entry and it appears automatically |
| `data/strains.min.json` | Generated slim copy fetched by the finder (`python scripts/build_min_data.py`) |
| `js/risk.js` | Risk-band logic (pure, unit-tested) |
| `js/strains.js`, `js/ranker.js` | Condition profiles and ranking UI |
| `test/` | `npm test` (Node 18+, no dependencies) |

```

npm test

```

## Deploy

GitHub Actions workflow `pages.yml`. In the repo settings, Pages → Source must be set to **GitHub Actions** (the workflow token cannot create the Pages site itself).

## Region and age gate

Every page is hidden until the visitor picks a region and answers the age question (legal age for that region, or medical authorization/support). Rules live in `_data/jurisdictions.json`, generated by `python scripts/build_jurisdictions.py` from English Wikipedia (pinned revision ids are in each entry's `verified` field).

- **Allowed:** places where recreational use or a medical program is legal per that source: the 13 Canadian provinces and territories (curated; Alberta 18, Quebec 21, others 19), 42 US states with an adult-use or medical program plus DC (24 states + DC are adult-use, age 21), and 55 other countries (8 adult-use, 47 medical-only).
- **Blocked:** 8 US states with no comprehensive medical program (listed so visitors there see a clear message), everything else, and "Somewhere else". "Partial" statuses (decriminalized, de facto, CBD-only) are NOT treated as legal.
- Medical-only places are legal only for patients, which is why the age question also offers "medical authorization or support".

Limits, stated plainly: this is a SECONDARY-source list (Wikipedia, with the US adult-use count cross-checked against an NCSL summary); official statutes were not checked, and laws change, so rerun the script and review the diff before relying on it. The region is self-declared (no IP lookup, so nothing is sent to a third party), the gate is client-side and bypassable, and the page source and data files are still public. It is a good-faith compliance control, not legal enforcement; hard enforcement would need server or CDN geo-blocking (for example a Cloudflare rule). Whether this content is lawful in a given place, including under Canada's Cannabis Act promotion rules, is a question for a lawyer.
## Known limits

- Risk bands in `js/risk.js` are relative to this dataset (cutoffs anchored to percentiles; see `node scripts/calibrate_risk.js`), not clinical cutoffs.
- Strains with fewer than 10 ratings are flagged as noisy.
- Only two claims on the Myths page are cited to published studies; the rest is interpretive guidance.
- Example profiles are fictional and carry per-profile cautions. For mood disorders, talk to a prescriber before using cannabis.
